01

カントーク夕食会（全体様式・卓 / ขันโตก）

チーク材や竹・籐で作られた円形脚付小机「トーク」。高僧や貴賓をもてなす最高礼のランナー宮廷・冠婚葬祭饗宴様式。1953年にチェンマイで舞踊鑑賞とセットの宴として現代に復興。

区分(食事/舞踊)

食事

食事の作法

卓（トーク）を跨ぐ行為や足で蹴る行為は神聖な食膳への不敬のため厳禁。足裏を卓や人・舞台に向けず、正座・あぐら・横座り（パップピアップ）で着席する。

02

ゲーン・ハンレー（北タイ風豚角煮カレー / แกงฮังเล）

ビルマ由来の煮込み料理「ヒンレー」が起源。ココナッツミルクを使わず、豚肉・生姜千切り・タマリンド・ニンニク漬け・ウコン等でじっくり煮込んだ甘酸っぱく濃厚なカントークの主菜。

区分(食事/舞踊)

食事

食事の作法

右手でカオニャオ（もち米）を一口大に丸め、カレーの濃厚なタレや柔らかい豚肉に絡めて食す。

03

ナムプリック・ヌム ＆ キャープムー（焼き青唐辛子ディップと豚皮揚げ）

炭火で丸焼きにした青唐辛子（プリック・ヌム）とニンニクを叩き潰した爽快な辛味ディップと、サクサクに二度揚げした豚皮。ランナー食文化を象徴する黄金のコンビネーション。

区分(食事/舞踊)

食事

食事の作法

丸めたもち米の端を指で少し窪ませてディップをすくい、カリカリのキャープムーや添えられた生野菜・蒸し野菜と一緒に口に運ぶ。

04

サイウア（チェンマイ・ハーブソーセージ / ไส้อั่ว）

レモングラス、コブミカンの葉、ガランガル、マクウェン（山椒）等の生ハーブと豚ひき肉を豚腸に詰め炭火で香ばしく焼いた名物ソーセージ。「ウア」はランナー語で「詰める」の意。

区分(食事/舞踊)

食事

食事の作法

輪切りにされたソーセージを生姜の薄切りや生キャベツ、もち米と一緒に一口で食べることで脂っこさを中和。

05

フォン・レップ（爪の舞 / ฟ้อนเล็บ）

親指を除く8本の指先に長い真鍮製の黄金の付け爪を装着し、緩やかなランナー古典管弦楽に合わせて舞う宮廷舞踊の最高峰。仏陀への帰依と客への心からの歓迎を表現。

区分(食事/舞踊)

舞踊

食事の作法

神仏への祈りと宮廷の精神が込められた神聖な演目のため私語を慎み静粛に鑑賞。演目終了時に盛大な拍手を送る。

06

フォン・ティエン（蝋燭の舞 / ฟ้อนเทียน）

両手に火を灯した蝋燭を持ち、照明を落とした薄暗い会場で幻想的な光の軌跡を描きながら舞う夜間祝祭・宮廷儀礼舞踊。仏教の灯明供養に由来。

区分(食事/舞踊)

舞踊

食事の作法

【フラッシュ撮影厳禁】暗転演出を損なうだけでなく、強烈な光で演者の視界を奪い火傷・転倒事故を招くためストロボ・フラッシュは必ずOFFにする。

07

フォン・ダーブ（剣の舞 / ฟ้อนดาบ）

ランナー古武術（ラーイ・チエン）に由来する勇壮な武芸舞踊。最大12本以上の鋭い刀剣を両手・口・肩・膝・足先に乗せ、自在に操りながらアクロバティックに舞う護身・魔除けの舞。

区分(食事/舞踊)

舞踊

食事の作法

演者の高度な集中力と危険を伴う演舞のため、立ち上がって視界を遮ったり急に演者に近づかないよう席から鑑賞。

08

タコン・グローン・サバッチャイ（勝利の太鼓舞 / ตีกลองสะบัดชัย）

古代の出陣式で兵士を鼓舞し勝利を宣言した軍鼓や寺院の大太鼓が起源。撥だけでなく肘・膝・頭・踵を使って全身で太鼓と銅鑼を打ち鳴らす躍動感あふれる民族芸能。

区分(食事/舞踊)

舞踊

食事の作法

演舞終了後や記念撮影時にチップを渡す際は両手で丁寧に渡す。演者の頭部や神聖な楽器・衣装に不用意に触れない。
