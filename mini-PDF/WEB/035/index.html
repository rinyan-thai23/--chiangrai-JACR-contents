01

サロー（Salor / สะล้อ）

半割りのココナッツ殻胴にチーク・紫檀の棹、2〜3弦。弓毛で擦り、哀愁を帯びつつも澄んだ伸びやかな高音の主旋律を奏でる。

種別

擦弦楽器（弓奏楽器）

使われる場面

弦楽合奏団「ウォン・サロー・ソー・スン」の主旋律、カントーク夕食会、新築祝い・寺院落慶法要、民謡伴奏。

02

スン（Seung / ซึง）

チーク等の堅木をくり抜いた胴に竹製フレット、4弦（2コース）。水牛角ピックで弾き、軽快で温かみのあるリズミカルな中低音を響かせる。

種別

撥弦楽器（リュート属）

使われる場面

サローとの二重奏・合奏、ランナー民謡（ソー）伴奏、宮廷・寺院の慶事、カントークディナー。

03

ピー・ジュム（Pee Jum / ปี่จุม）

竹管に真鍮リードを埋め込んだ伝統笛。低音（メー）〜高音（ゴイ）等の長短3〜5本を1組（ジュム）として合奏。温かく柔らかな持続音。

種別

木管楽器（フリーリード気鳴楽器）

使われる場面

北タイ伝統歌謡「カップ・ソー・ランナー」の専属伴奏、結婚式、新築祝い、得度式（ポイ・サーンロン）。

04

グローン・サバッチャイ（Glong Sabat Chai / กลองสะบัดชัย）

牛革を張った大太鼓・小太鼓・銅鑼のセット。バチでの連打に加え肘・膝・頭など全身を使ったアクロバティックな演舞と地響きのような大音響。

種別

打楽器（膜鳴大太鼓）

使われる場面

古代は軍陣太鼓、現代はイーペン祭り、ソンクラーン、寺院大祭、記念式典オープニングファンファーレ、魔除け。

05

フォン・レップ（爪の舞 / ฟ้อนเล็บ / Fon Leb）

両手8本の指先に約15cmの真鍮製黄金の長い付け爪を装着。ダーラーラッサミー王妃が洗練させた宮廷様式で、指先の優美なしなりと整然とした隊列美。

種別

伝統舞踊（宮廷・寺院儀礼舞踊）

使われる場面

寺院の落慶法要（ポイルアン）、仏教祝祭、国家貴賓の歓迎式典、カントークディナー。

06

フォン・ティエン（蝋燭の舞 / ฟ้อนเทียน / Fon Thian）

両手に灯した本物の蝋燭を持ち、薄暗がりの空間で火を絶やさず手首を滑らかに回転させ、光の幻想的な軌跡を描きながら舞う仏陀への光明供養。

種別

伝統舞踊（夜間奉納舞踊）

使われる場面

ウィサーカブーチャー（仏誕節）やイーペン祭の夜間仏教大祭、寺院境内での夜間奉納、祝賀夜宴。

07

フォン・ダーブ（剣の舞 / ฟ้อนดาบ / Fon Dab）

古代ランナー古武術「ラーイ・チエン」に由来。鋭利な刀剣（2〜16本）を両手・口・肩・膝・足先に乗せ、落とさず敏捷・勇壮に旋回・跳躍する。

種別

伝統舞踊（武術舞踊）

使われる場面

出陣・戦勝祈願、武運長久、悪霊退散・魔除け儀礼、ソンクラーン・伝統祝祭のクライマックス。

08

フォン・サーオ・マイ（絹紡ぎの舞 / ฟ้อนสาวไหม / Fon Sao Mai）

北タイ伝統絹織物の桑摘み・養蚕・繭煮・糸引き・機織りの工程を、しなやかな指先と腕の流れるような曲線美で詩情豊かに表現する生活文化舞踊。

種別

伝統舞踊（民俗生活描写舞踊）

使われる場面

伝統工芸フェスティバル、収穫感謝祭、カントークディナー、文化交流公演。
