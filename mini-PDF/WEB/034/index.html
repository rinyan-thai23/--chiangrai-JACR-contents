01

バーン・パーミエン（Ban Pa Mieng / บ้านป่าเหมี้ยง）

県名

ランパーン県（ムアンパーン郡・チェーソーン国立公園近郊）

体験できる活動

伝統的な噛み茶「ミエン（発酵茶葉）」の手摘み・発酵体験、森林アラビカコーヒー焙煎、清流沿いの木造ホームステイ、2〜3月の白花野生ラン「ドーク・セッティ祭り」観賞。

予約・訪問方法

パーミエン村コミュニティ観光企業体（วิสาหกิจชุมชนโฮมสเตย์บ้านป่าเหมี้ยง）へ事前電話予約。チェーソーン国立公園から山道約70km（急坂のため運転注意）。

02

バーン・ローチャ（Ban Lorcha / บ้านหล่อชา / アカ族生きた博物館）

県名

チェンライ県（メーチャン郡・ドイメーサロン山麓国道1089号線沿い）

体験できる活動

アカ族（Akha）の伝統文化保全モデル村。精霊門（ロホ・ロン）の儀礼解説、泥藍染め、伝統鍛冶屋での農具製作、竹楽器演奏、民族ブランコ、罠猟デモ。

予約・訪問方法

ポピュレーション・コミュニティ開発協会（PDAチェンライ支部）または現地エントランス受付センターで直接受付（事前団体予約推奨）。

03

バーン・メーカンポン（Ban Mae Kampong / บ้านแม่กำปอง）

県名

チェンマイ県（メーオン郡・標高1,300m）

体験できる活動

タイCBTの草分けモデル。清流沿いの木造高床式ホームステイ、アラビカ珈琲栽培・焙煎、伝統茶葉枕（消臭安眠枕）作り、メーカンポン滝ハイキング、小水力発電所見学。

予約・訪問方法

メーカンポン村コミュニティサービス協同組合（สหกรณ์บริการชุมชนบ้านแม่กำปอง）公式窓口へ事前予約。道幅狭小のため村営シャトルバン等の利用推奨。

04

バーン・ジャーボー（Ban Jabo / บ้านจ่าโบ่ / 黒ラフ族集落）

県名

メーホンソーン県（パンマパー郡・標高900m）

体験できる活動

ラフ族（黒ラフ）の集落。断崖絶壁に足を投げ出して食べる名物「崖っぷちヌードル」と早朝の大雲海パノラマ、伝統手織り・竹編み、古代木棺の眠るピーメン洞窟探検。

予約・訪問方法

バーン・ジャーボーCBT観光グループ公式Facebookまたは電話での事前予約。パーイから国道1095号線経由約55km（ワインディングロード）。

05

バーン・フワイヒー（Ban Huai Hee / บ้านห้วยฮี้ / カレン族集落）

県名

メーホンソーン県（ムアン郡・ドイプイルアン山麓）

体験できる活動

ポー・カレン族の先駆的エコビレッジ。森林有機シェードコーヒーの手摘み・精製、標高1,722mのドイプイルアン山頂トレッキング（360度大雲海）、腰機による伝統機織り。

予約・訪問方法

フワイヒーCBTグループへ事前予約（完全予約制・ガイド必須）。急傾斜悪路のため4WD車必須（村の送迎手配推奨）。

06

バーン・ノンブア／タイ・ルー集落（Ban Nong Bua - Tai Lue / บ้านหนองบัว）

県名

ナーン県（ターワンパー郡・プア隣接）

体験できる活動

タイ・ルー族（Tai Lue）の伝統文化ヘリテージ。寺院ワット・ノンブアの歴史的古壁画鑑賞、伝統高機による「流水紋（ラーイ・ナムライ）」手織り体験、清流淡水海苔カイ加工。

予約・訪問方法

バーン・ノンブア・タイ・ルー文化保存会またはDASTA特別地域6号（ナーン歴史都市）推進ネットワーク経由で事前予約。国道1080号線完全舗装路。

07

バーン・パーボンピアン（Ban Pa Pong Piang / บ้านป่าบงเปียง / 絶景棚田）

県名

チェンマイ県（メーチェム郡・ドイインタノン山麓）

体験できる活動

「タイで最も美しい棚田」と称されるカレン族集落。7〜8月水鏡、9〜10月緑の絨毯、11月黄金の稲穂。電気のないランプの灯りと満天の星空・朝霧に包まれるオフグリッド宿泊。

予約・訪問方法

各棚田農家ホームステイへ直接電話事前予約（稲作期の7〜11月限定営業多数）。悪路急坂のためインタノン側から4WD送迎車手配必須。
