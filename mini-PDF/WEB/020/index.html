01

本当にありがとうございます

ขอบคุณมาก (khòop-khun mâak)

チェンライ北タイ語

ยินดีจ๊าดนัก (yin-dii câat-nák)

発音(カタカナ)

インディー・ジャート・ナック（女性: +ジャオ / 男性: +クラップ）

使う場面

買い物や食事の後、助けてもらった時に感謝を伝える場面。標準タイ語「コープクン」の代わりに使うと現地の人に驚かれ大変喜ばれる。

02

とても美味しいです！

อร่อยมาก (à-ròy mâak)

チェンライ北タイ語

ลำขนาด (lam khá-nàat) / ลำแต๊แต๊ (lam tɛ́ɛ-tɛ́ɛ)

発音(カタカナ)

ラム・カナート / ラム・テーテー

使う場面

カオソーイやナムギョウ等の食堂・屋台で料理を褒める場面。「ラム」＝美味しい、「カナート」＝とても、「テーテー」＝本当に。笑顔で親近感倍増。

03

いくらですか？

เท่าไหร่ (thâo-rày)

チェンライ北タイ語

เต้าใด (tâo-day)

発音(カタカナ)

タオダイ（例: タオダイ・ジャオ？ / タオダイ・クラップ？）

使う場面

市場（タラート）やナイトバザール、屋台、ソンテウで料金・価格を尋ねる場面。「タオライ」ではなく「タオダイ」と聞くのが北タイ流。

04

もう少し安くしてくれますか？

ลดอีกหน่อยได้ไหม (lót ìik nɔ̀y dâi-mǎi)

チェンライ北タイ語

ลดแหมหน่อยได้ก่อ (lót hɛ̌ɛm nɔ̀y dâi kɔ̀ɔ)

発音(カタカナ)

ロット・ヘーム・ノーイ・ダイ・ゴー？

使う場面

市場やお土産店で角を立てずに柔らかく値引き交渉をする場面。「ヘーム」＝さらに・もう一度、「ダイ・ゴー」＝できますか。

05

どこへ行くの？ / どこ行ってたの？

ไปไหนมา (pay nǎi maa)

チェンライ北タイ語

ไปตางใดมา (pay taaŋ-day maa) / ไปแอ่วตางใด (pay ɛ̀ɛw taaŋ-day)

発音(カタカナ)

パイ・ターンダイ・マー？ / パイ・エーオ・ターンダイ？

使う場面

街中やゲストハウスで顔見知りに会った時の日常の気軽な挨拶。「エーオ」＝遊びに行く・観光する。北タイで最も頻繁に交わされる声かけ。

06

すごく・とても・本当に（強調語）

มาก / จริงๆ (mâak / ciŋ-ciŋ)

チェンライ北タイ語

ขนาด (khá-nàat) / แต๊แต๊ (tɛ́ɛ-tɛ́ɛ)

発音(カタカナ)

カナート / テーテー

使う場面

形容詞の後ろに付けて強調する場面。暑い＝「ローン・カナート」、寒い＝「ナーオ・カナート」、美しい＝「ガーム・カナート」。

07

そうです・その通りです

ใช่แล้ว (chây lɛ́ɛw)

チェンライ北タイ語

แม่นแล้ว (mɛ̂n lɛ́ɛw) / แม่น (mɛ̂n)

発音(カタカナ)

メン・レーオ / メン（女性: メン・ジャオ / 男性: メン・クラップ）

使う場面

相手の質問や確認に「はい、そうです」と肯定・相槌を打つ場面。標準タイ語の「チャイ」の代わりに「メン」を用いる。

08

すみません・ごめんなさい

ขอโทษนะ (khɔ̌ɔ-thôot ná)

チェンライ北タイ語

สุมาเต๊อะ (sù-maa tɤ́)

発音(カタカナ)

スマ・トゥー（または スマ・トゥッ）

使う場面

人混みを通り抜ける時、呼び止める時、ちょっとした非礼を詫びる場面。穏やかで優しい北タイ特有のお詫びフレーズ。
