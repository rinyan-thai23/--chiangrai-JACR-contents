01

はい / 〜です（女性丁寧語・返事）

ค่ะ / คะ (khâ / khá)

北タイ語

เจ้า

発音

ジャオ（高下降調・柔らかく伸ばす）

ニュアンス解説

北タイを象徴する極めて上品で柔らかな女性丁寧語。標準語のように平叙文（ค่ะ）と疑問文（คะ）で分ける必要がなく、肯定・返事・文末すべて「เจ้า」で完結する。

02

美しい・綺麗

สวย (sǔay)

北タイ語

งาม

発音

ガーム（中平調・長音）

ニュアンス解説

標準語では古語・雅語だが北タイでは日常会話の第一選択語。景色・容姿・工芸品等すべてに用いる。「とても綺麗」は強調のカナートを付けて「ガーム・カナート」。

03

ご飯を食べる

กินข้าว (kin khâaw)

北タイ語

กิ๋นข้าว

発音

ギン・カーオ（ギン：上昇調、カーオ：下降調）

ニュアンス解説

動詞「食べる」が上昇調（マイチャッタワー音）に変化。「ご飯食べた？」は日常挨拶で「ギンカーオ・レーオ・カー？」、夕食は「ギンカーオ・レン」と言う。

04

話す・喋る

พูด (phûut)

北タイ語

อู้

発音

ウー（下降調・長音）

ニュアンス解説

北タイ語固有の最重要動詞。「北タイ語を話す」は「ウー・カムムアン（อู้คำเมือง）」と言い、地域アイデンティティを表す。「冗談を言う」は「ウー・レン」。

05

遊びに行く・観光する

ไปเที่ยว (pay thîaw)

北タイ語

ไปแอ่ว

発音

パイ・エーオ（パイ：中平調、エーオ：低平〜下降調）

ニュアンス解説

「散策する・遊び歩く」の意。昔、夜間に男性が女性の家を訪ねて歌を詠み交わした求愛伝統「エーオ・サーオ」に由来。現在は「北タイを旅する＝エーオ・ヌア」等で多用。

06

私（一人称） / あなた（二人称）

【私】ฉัน/ผม 【あなた】คุณ/เธอ

北タイ語

【私】ข้าเจ้า / เฮา 【あなた】ตั๋ว / สู

発音

【私】カージャオ / ハオ 【あなた】トゥア / スー

ニュアンス解説

女性の一人称丁寧語は「カージャオ」。親しい間柄の一人称は「ハオ」（標準語raoのR→H変化）。親しい同年代への二人称は「トゥア」（あなた/君）。

07

嘘・冗談・からかう

โกหก (koo-hòk)

北タイ語

ขี้จุ๊

発音

キー・ジュ（キー：下降長音、ジュ：高短促音）

ニュアンス解説

性質を表す「キー」＋「ジュ（欺く・からかう）」。悪意ある嘘だけでなく「嘘ばっかり〜」「からかわないで」と親しい間柄で冗談めかして頻繁に使う定番表現。

08

見る・眺める（〜してみる）

ดู / มอง (duu / mɔɔŋ)

北タイ語

ผ่อ

発音

ポー（低平〜下降調・長音）

ニュアンス解説

「見る」を表す固有動詞。「映画を見る＝ポー・ナン」のほか、標準語の「ลอง...ดู（〜してみる）」構文として文末に置き「食べてみて＝ローン・ギン・ポー」等と使う。
