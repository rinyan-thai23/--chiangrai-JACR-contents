01

ポンプラバート温泉（น้ำพุร้อนโป่งพระบาท）

所在地

チェンライ県ムアン郡バーンドゥー地区（市街から北へ約8km、国道1号経由車で約15分）

風呂の種類

無料屋外足湯、個室入浴棟（1〜4名用個室）、共同浴場

泉質・効能

弱アルカリ性単純硫黄泉（源泉温度48〜50℃）。フッ素・硫黄成分を含み疲労回復・関節痛緩和・血行促進に優れる。※成分が強いため飲用厳禁。

料金

入場・足湯: 無料 / 個室風呂（1時間）: 1名70THB、2名100THB、3名140THB、4名180THB / タイマッサージ: 約150THB/時

設備・備考

営業時間07:00–17:00（年中無休）。バーンドゥー準自治体運営。駐車場・売店・東屋・温泉卵茹で場・タイ古式マッサージ完備。市街地から最も近い人気温泉。

02

パートゥン温泉（น้ำพุร้อนป่าตึง / ห้วยหินฝน）

所在地

チェンライ県メーチャン郡パートゥン地区（市街から北へ約35km、国道1089号沿い）

風呂の種類

屋外階段状足湯（温度別）、個室風呂（一般・VIP計8室）、湯掛けシャワー室（6室）、高さ10m自噴温泉噴水

泉質・効能

アルカリ性単純硫黄泉（源泉温度70〜109℃の超高温自噴泉）。リウマチ・神経痛緩和、冷え性改善、美肌効果。

料金

入場・足湯: 無料 / 個室風呂: 約20〜50THB/名 / タイマッサージ: 約150〜200THB/時 / 温泉卵セット: 約20〜30THB

設備・備考

営業時間06:00–18:00（年中無休）。パートゥン行政機構運営。竹籠入り卵を70℃以上の源泉池に浸して作る温泉卵が名物。広大な緑地公園・東屋併設。

03

フアイマークリアム温泉（น้ำพุร้อนห้วยหมากเลี่ยม）

所在地

チェンライ県ムアン郡ドイハーン地区（ラムナムコク国立公園内、市街から西へ約19km）

風呂の種類

コック川沿いの天然露天足湯プール、個室入浴棟、川辺の岩盤湧出泉

泉質・効能

弱アルカリ性単純硫黄鉱泉（源泉温度56〜67℃）。フッ素・ヨウ素・硫酸塩を含み、疲労回復・リラクゼーション・皮膚病緩和。

料金

国立公園入場: 原則無料（※時期により外国人100〜200THBの場合あり） / 足湯: 無料 / 個室風呂: 約30〜50THB

設備・備考

営業時間08:00–17:00（年中無休）。国立公園DNP管理。コック川の雄大なリバービュー、キャンプ場、バンガロー、遊歩道併設。ボートでのアクセスも可能。

04

パーセート温泉（น้ำพุร้อนผาเสริฐ）

所在地

チェンライ県ムアン郡ドイハーン地区パーセート村（市街から西へ約19km、フアイマークリアム至近）

風呂の種類

大型屋外露天温泉プール、個室風呂棟、屋外足湯水路

泉質・効能

単純硫黄温泉（源泉温度約60〜70℃）。筋肉痛・関節痛緩和、冷え性改善、デトックス。

料金

入場・足湯: 無料 / 屋外プール: 約30〜50THB / 個室風呂: 約50〜80THB / タイマッサージ: 約150〜200THB/時

設備・備考

営業時間08:00–17:00（年中無休）。ドイハーン行政機構運営。家族連れで泳げる大型温水プール、マッサージ棟、食事処、温泉卵場が揃う総合クア施設。

05

メーカチャン温泉（น้ำพุร้อนแม่ขะจาน）

所在地

チェンライ県ウィエンパーパオ郡メージェディーマイ地区（国道118号Km64-65、市街から南西約85km）

風呂の種類

国道両側の無料足湯水路、民間スパ個室ミネラルバス、超高温ボイリングポンド（温泉卵専用池）

泉質・効能

強硫黄アルカリ性単純高温泉（源泉温度80〜98℃の超高温泉）。ドライブ疲労回復、血行促進、足腰のコリ解消。

料金

入場・足湯: 無料 / 民間個室風呂: 約50THB/名 / 温泉卵セット（生卵・ウズラ＋タレ）: 約20〜40THB

設備・備考

ドライブイン24時間開放（足湯・店舗06:00–19:00）。チェンライ〜チェンマイ間を結ぶ国道沿いの有名休憩所。約3分で半熟卵ができる熱湯池、特産品市場併設。
