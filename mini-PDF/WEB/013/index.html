01

カオソーイ・ポーチャイ（Khao Soi Pho Chai / ข้าวซอยพอใจ）

チェンライ伝統の「あっさり澄んだスープ仕立て」。ココナッツミルクのしつこさがなく、スパイスが軽やかに香る。平打ち卵麺とサクサク揚げ麺の相性が抜群。

看板メニュー

カオソーイ・ガイ（鶏肉）/ エビ / 魚、澄ましナムギョウ、サイウア

営業時間

08:00〜16:00（毎日営業 / 売り切れ仕舞い）

価格帯(THB)

40〜60THB

02

ナムギョウ・パースック（Pa Suk Nam Ngiao / ป้าสุข น้ำเงี้ยว）

創業50年超の殿堂店（Wongnai受賞常連）。乾燥トゥアナオ（発酵大豆）の香ばしいコク、完熟トマトの爽やかな酸味、大粒豚ひき肉、キワタの花（ドーク・ギョウ）、豚血豆腐が絶妙に調和した濃厚仕込み。

看板メニュー

カノムジーン・ナムギョウ（豚/牛）、クイッティオ・ナムギョウ、カオカンジン

営業時間

09:30〜14:30（月曜定休 / 昼過ぎ売り切れ終了あり）

価格帯(THB)

40〜60THB

03

カオソーイ・タオゲーエーク（Khao Soi Thao Gae Ek / ข้าวซอยเถ้าแก่เอ๊ก）

ワット・プラケオ近くの濃厚派名店。スパイスを効かせた深みのあるカレースープに、ホロホロになるまで煮込まれた大ぶり牛肉が絶品。手打ち生麺のコシが強い。

看板メニュー

カオソーイ・ヌア（じっくり煮込んだ特選牛肉）、カオソーイ・ムー（豚）

営業時間

08:30〜15:30（毎日営業）

価格帯(THB)

45〜65THB

04

カオソーイ・イスラム（Khao Soi Islam / ข้าวซอยอิสลาม）

創業50年以上の雲南チンホー系ハラール老舗。クミンやカルダモンが芳醇に香る本格カレースープ。自家製高菜漬け（パッカアド・ドーン）の自然な酸味が味を引き締める。

看板メニュー

カオソーイ・ヌア/ガイ、カオモック（イスラム風スパイス炊き込みご飯）、牛皮揚げ

営業時間

07:00〜16:00（毎日営業 / 午後売り切れ次第終了）

価格帯(THB)

40〜60THB

05

ナムギョウ・パーヌアン（Nam Ngiao Pa Nuan / น้ำเงี้ยวป้านวล）

地元民に長年愛される伝統ナムギョウ老舗。豚骨ベースにトゥアナオの旨味とトマトの酸味が溶け込んだ王道の北タイ・チェンライスープ。太米麺（センヤイ）との組み合わせも人気。

看板メニュー

ナムギョウ・カノムジーン（豚肉/スペアリブ）、ナムギョウ・センヤイ、豚皮揚げ

営業時間

08:00〜15:00（毎日営業）

価格帯(THB)

35〜50THB
