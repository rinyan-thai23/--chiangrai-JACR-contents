No. 048 / タイ・チェンライ旅ガイド

タイの「幸運を呼ぶ伝統猫（シャム・カオマニー等）」種類・伝承図鑑

古文書『タムラー・メーオ』に記載された、タイ原産の珍しい猫の種類と縁起の良い伝承。

01

ウィチェンマート（シャム猫 / Siamese）

วิเชียรมาศ (月のダイヤモンド)

淡いクリーム色の短毛、末端9箇所（耳2・顔1・足4・尾1・生殖器1）に濃褐色ポイント、サファイアブルーの瞳。

古文書『タムラー・メーオ』最高峰の吉兆猫。飼い主に金銀財宝・富・名声をもたらし、高官への立身出世を叶える。

02

コラート（シーサワット / マーレート / Korat）

โคราช (สีสวาด / มาเลศ / ดอกเลา)

先端が銀色に輝くシルバーブルー（ススキの穂色）、ハート型の顔、露滴のようなエメラルドグリーンまたは琥珀色の瞳。

イサーン地方の雨乞い儀礼（ヘーナーンメーオ）の聖猫。豊作・平安・幸福な婚姻・商売繁盛をもたらす。

03

カオマニー（白玉猫 / ダイヤモンドアイ / Khao Manee）

ขาวมณี (ขาวปลอด)

混じり気のない純白（スノーホワイト）、左右の瞳の色が異なるオッドアイ（青×黄/緑）または澄んだブルー。

ラーマ5世が王室内で愛育した秘蔵猫。長寿・家運隆盛・名声・あらゆる災厄除けをもたらす。

04

スパラック（赤銅猫 / トーンデーン / Suphalak）

ศุภลักษณ์ (ทองแดง)

全身が均一に艶めく赤銅色（コッパーブラウン）、黄金色・琥珀色の輝く瞳、赤褐色のヒゲと肉球。

「スパラック＝高貴な吉祥の相」。飼い主に強大な権勢・尊厳・富を授け、悪霊や邪気を完全に打ち払う守護猫。

05

コーニャ（漆黒猫 / 威風堂々たる黒猫 / Konja）

โกนจา (ดำปลอด)

毛根・肉球・爪・口腔内まで完全な漆黒、ライオンのように堂々たる歩行、満開のヘチマ花のような菊花黄金色の瞳。

飼い主の言葉に強い権威と説得力を持たせ、商談・交渉を成功に導き、財産を堅固に守護する。

06

サムサウェート（霜降り黒猫 / Sam Saweet）

แซมเสวตร

漆黒の地毛の中に極細の白毛が霧や霜のように均一に混じるフロストブラック、ホタルの光のように瞬く淡緑色の瞳。

官僚の立身出世・爵位授与の吉兆。主君や上官に重用され、官位・禄高が飛躍的に向上する。

07

ニンララット（黒宝石猫 / 全身黒玉猫 / Ninlarat）

นิลรัตน์

全身が濡れ羽色の漆黒で、被毛だけでなく爪・歯・舌・目（虹彩）に至るまで全身すべてが黒く輝く極めて希少な相。

金銀財宝が無尽蔵に湧き出て蔵を満たし、一族が末永く裕福に繁栄し続ける至高の財運招来猫。

08

ニンラチェック（白輪黒猫 / ネックレースキャット / Ninlachak）

นิลจักร

全身は艶やかな漆黒で、首の周囲にのみ白いチョーカーや首飾りを巻いたように純白の毛が一周する。瞳は琥珀色。

土地や不動産などの資産が次々と増え、代々にわたり家業と富が繁栄し続けるとされる。
