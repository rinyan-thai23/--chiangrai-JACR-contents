01

バンコク病院チェンライ

โรงพยาบาลกรุงเทพเชียงราย (Bangkok Hospital Chiang Rai)

タイ最大手BDMS傘下の私立総合病院。24時間ER、ICU/CCU、脳神経、循環器、一般外科、整形外科、小児科、高度画像診断（CT/MRI）完備。

日本語対応有無

対応あり（国際医療サービス部門IMSあり・医療コーディネーター/通訳手配可・海外保険キャッシュレス対応）

電話番号

代表: 052-051-800 / 救急直通(24h): 052-051-913 / 短縮: 1719

救急受診手順

①保険会社アシスタンスへ連絡しキャッシュレス手配（急患時は直接救急直通052-051-913へ） ②パスポート原本・保険証券・クレカ持参 ③ER受付で提示しトリアージ・診察 ④保険支払い保証書受領または立替精算。

02

オーバーブルック病院

โรงพยาบาลโอเวอร์บรุ๊ค (Overbrook Hospital)

1903年創立のキリスト教系私立総合病院。市内中心部（時計塔近く）。24時間ER、ICU、一般内科・外科、整形外科、産婦人科、小児科、人工透析。外務省医務官情報掲載。

日本語対応有無

英語対応可（医師・主要スタッフ。日本語は保険会社電話通訳併用推奨・海外保険キャッシュレス対応課あり）

電話番号

代表: 053-711-366 / 救急直通(24h): 053-910-100（医療連携課内線: 4367, 4368）

救急受診手順

①市街中心部から好アクセス。救急は053-910-100へ連絡 ②パスポート・保険証券・医療連携課への提示 ③診察・検査 ④キャッシュレス承認または窓口精算（英文診断書・明細付き領収書を必ず取得）。

03

カセームラード病院スリブリン

โรงพยาบาลเกษมราษฎร์ ศรีบุรินทร์ (Kasemrad Sriburin Hospital)

タイ大手BCH傘下の私立総合病院（国道1号線沿い）。24時間ER（Mobile ICU高規格救急車配備）、ICU、心臓病センター、脳血管・神経、整形・外傷外科。外務省掲載。

日本語対応有無

英語対応可（外国人患者窓口あり。日本語は電話通訳サポート併用推奨・海外保険キャッシュレス対応）

電話番号

代表: 053-910-999 / 救急ホットライン(24h): 053-700-200

救急受診手順

①救急ホットライン053-700-200へ電話（救急車要請可） ②パスポート原本・保険証券持参 ③ER窓口で受付・トリアージ受診 ④海外保険直接請求手続きまたは精算（英文診断書取得）。

04

チェンライ・プラチャヌクロ病院

โรงพยาบาลเชียงรายประชานุเคราะห์ (Chiangrai Prachanukroh Hospital)

タイ保健省直轄の第3次救急中核公立総合病院（800床超）。重症外傷センター（Level 1 Trauma相当）、高度ICU、心臓カテーテル、脳神経外科。県内最高峰の救命設備（※混雑度高）。

日本語対応有無

日本語非対応（公立病院のため基本的にタイ語・医師により英語可。海外保険キャッシュレス原則不可・現地立替払い）

電話番号

代表: 053-910-600 / 080-125-5555 / 救急直通: 093-138-6690 / 国家救急: 1669

救急受診手順

①重症救急時は1669または病院直通093-138-6690へ要請 ②パスポート原本・現金/クレカ持参 ③ER受診 ④窓口で自己立替払いし、帰国後保険請求用の「英文診断書（Medical Certificate）」と「項目別領収書」を必ず発行受領。

05

緊急通報・救急搬送窓口（警察・総領事館）

ศูนย์รับแจ้งเหตุฉุกเฉินและสถานกงสุล (Emergency & Consulate Services)

事故・急病・事件発生時の緊急通報および邦人保護支援窓口。1155は通訳仲介・トラブル対応、総領事館は緊急時助言・家族連絡支援。

日本語対応有無

タイ国家救急1669（タイ語/一部英）、ツーリストポリス1155（24h英語・多言語）、在チェンマイ日本総領事館（日本語）

電話番号

救急: 1669 / 観光警察: 1155 / 警察: 191 / 在チェンマイ日本総領事館: 052-012-500

救急受診手順

①急病・大怪我時は「1669」（公立救急車）または「1155」（ツーリストポリス）へ通報 ②居場所・症状を英語/タイ語で伝達 ③パスポート原本を携行 ④重大事案時は在チェンマイ日本総領事館（052-012-500）へ連絡相談。
