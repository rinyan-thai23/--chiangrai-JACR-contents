01

ライチ（Lychee / ลิ้นจี่ / ホンフワイ種・ジャカパット種）

収穫ピーク(月)

5月〜6月（早生種は4月下旬〜）

主な生産エリア

チェンライ県メースワイ郡・ムアン郡、チェンマイ県ファーン郡、パヤオ県メーチャイ郡（GI認定）

選び方・味わい

果皮が鮮紅色でトゲが適度に平らになったものが完熟。肉厚で極めてジューシー、上品な芳香と高糖度・爽やかな酸味。

02

ロンガン / 竜眼（Longan / ลำไย / ドー種・ビエウキアオ種）

収穫ピーク(月)

7月〜8月（最盛期・乾期外技術で通年一部出荷）

主な生産エリア

ランプーン県（タイ最大の主産地・GI認定）、チェンマイ県サラピー郡・サンパトン郡

選び方・味わい

果皮が均一な黄褐色で張りがあり大玉。果肉は半透明で引き締まった弾力があり蜂蜜のように濃厚な甘み。黄金乾燥ロンガンも名物。

03

イチゴ（Strawberry / สตรอว์เบอร์รี / 王室品種80・品種88）

収穫ピーク(月)

12月〜2月（収穫期全体は11月〜4月）

主な生産エリア

チェンマイ県サモーン郡（タイ最大の苺産地・毎年2月苺祭り）、チェンライ県ドイトゥン・プーチーファー山麓

選び方・味わい

ヘタ際まで鮮紅色に均一に着色しツヤがあるもの。高糖度で酸味との調和が優れ、芳醇な香りとしっかりした果肉（王室プロジェクト開発）。

04

温帯みかん（Tangerine / ส้มสายน้ำผึ้ง / ソム・サイナムプン）

収穫ピーク(月)

11月〜2月（涼期の寒暖差で糖度極大化）

主な生産エリア

チェンマイ県ファーン郡（GI認定「ソム・ファーン」）、チェンライ県メースワイ郡

選び方・味わい

皮が薄く果汁の重みがあるもの。「蜂蜜の小川」の名通り、濃厚な甘みとコク、適度な酸味が調和し果汁が溢れる高級柑橘。

05

チェンライ・プーリー・パイナップル（Phulae Pineapple / สับปะรดภูแล）

収穫ピーク(月)

通年（2大ピーク：5月〜6月および12月〜1月）

主な生産エリア

チェンライ県ムアン郡（ナーンレー準郡・タースット準郡・バーンドゥー準郡・GI認定産品）

選び方・味わい

手のひらサイズの小ぶり（300〜500g）。最大の特長は「芯までサクサク食べられる」こと。黄金色の果肉で濃厚な甘みとジューシーな食感。

06

高冷地アボカド（Avocado / อะโวคาโด / ハス種・ブース7種）

収穫ピーク(月)

7月〜10月（ハス種は9〜11月）

主な生産エリア

チェンマイ県ドイインタノン・ドイアンカーン、チェンライ県ドイトゥン・ドイチャン

選び方・味わい

ハス種は果皮が濃緑から黒紫色に変わり軽く押して弾力があるものが食べ頃。標高1,000m以上の冷涼気候で良質な油分を蓄えクリーミーで濃厚なナッツ風味。

07

高冷地富有柿（Persimmon / พลับ / 完全甘柿Fuyu種）

収穫ピーク(月)

8月〜10月（最盛期は8月下旬〜9月）

主な生産エリア

チェンマイ県ファーン郡（ドイアンカーン王室ステーション）、チェンライ県メーファールアン郡（ドイトゥン）

選び方・味わい

全体が鮮やかなオレンジ〜朱色に均一に色づきハリがあるもの。渋抜き不要の完全甘柿で、サクサクとした歯ごたえと上品で澄んだ甘み。

08

高冷地アラビカコーヒー豆 ＆ 高山茶（Arabica Coffee & Highland Tea）

収穫ピーク(月)

コーヒー：11月〜2月 / 高山茶：通年（3〜5月春新茶が最高峰）

主な生産エリア

チェンライ県メースワイ郡ドイチャン（GI認定珈琲）、メーファールアン郡ドイトゥン（GI認定）・メーサロン（烏龍茶・金萱茶）

選び方・味わい

完熟レッドチェリーを手摘みした珈琲は華やかな柑橘の酸味とナッツの余韻。一芯二葉手摘みの高山茶は蘭のような高貴なアロマと深い余韻（回甘）。
