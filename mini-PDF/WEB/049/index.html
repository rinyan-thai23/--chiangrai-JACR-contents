01

セン・イッター（Sen Ittha / 左主経絡）

対応部位

臍左側〜左大腿後面〜背骨左側〜首筋〜頭頂〜左鼻孔

期待される効果

頭痛、首肩こり、眼精疲労、風邪の初期症状、鼻づまり、副交感神経のリラックス

押す・伸ばす手順

背骨の左側指2本分のラインを親指で腰から首へ垂直圧で押し上げ、首を右斜め前に倒して左首筋を深く伸ばす。

02

セン・ピンカラー（Sen Pingkhla / 右主経絡）

対応部位

臍右側〜右大腿後面〜背骨右側〜首筋〜頭頂〜右鼻孔

期待される効果

慢性腰痛、背中の張り、消化器機能（肝・胆）の調整、全身の倦怠感・疲労回復

押す・伸ばす手順

背骨の右側ラインを親指で下から上へ指圧し、腰に手をあてて上体をゆっくり後方に反らし体幹前面を伸ばす。

03

セン・スマナー（Sen Sumana / 中枢経絡）

対応部位

臍上部〜腹部正中〜鳩尾〜胸骨中央〜喉〜舌先

期待される効果

動悸、息切れ、胸のつかえ、気管支炎、精神的ストレス・不眠の鎮静

押す・伸ばす手順

両手の平を胸骨中央（膻中）に重ねて温めながら深呼吸と共に圧迫し、両手を鎖骨下に当て顎を上げて喉を伸ばす。

04

セン・ガラタリー（Sen Kalathari / 四肢経絡）

対応部位

臍上部〜腕内側・手の指先＆脚前面・足の指先の四肢全体

期待される効果

手足の冷え性、四肢のむくみ・しびれ、関節痛、全身の血液循環促進

押す・伸ばす手順

足裏を合わせて座る合蹠のポーズで前屈し四肢をストレッチ、仰向けで手足を真上に上げ細かく揺らす。

05

セン・サハスランシー（Sen Sahatsarangsi / 左眼ライン）

対応部位

臍左側〜左太もも内側〜足底〜太もも外側〜脇腹〜左目

期待される効果

左目の眼精疲労、かすみ目、目の奥の重み、顔面神経痛、消化促進

押す・伸ばす手順

左太もも内側を付け根から膝へ揉みほぐし、左目の眉頭からこめかみ（太陽穴）にかけて指先で円を描いて指圧する。

06

セン・タワリー（Sen Thawari / 右眼ライン）

対応部位

臍右側〜右太もも内側〜足底〜太もも外側〜脇腹〜右目

期待される効果

右目の疲れ、ドライアイ、めまい、頭のふらつき、側頭部痛の緩和

押す・伸ばす手順

右脚を伸ばして前屈し脚全体のセンを伸ばし、右目の周りの骨の縁を指先でトントンと優しくタッピングする。

07

セン・ジャンタブサン（Sen Chanthaphusang / 左耳ライン）

対応部位

臍左側〜左胸部〜鎖骨上窩〜首左側（胸鎖乳突筋）〜左耳

期待される効果

耳鳴り、めまい、難聴、首側面のコリ、耳周りのリンパ循環促進

押す・伸ばす手順

左耳たぶをつまんで外・上下へ軽く引っ張り回し、耳下から鎖骨へ向かって首筋を上から下へ優しく撫で下ろす。

08

ルーシーダットン（仙人体操 / 伸びの基本ポーズ）

対応部位

体幹・背骨・胸郭・骨盤・主要10セン全体

期待される効果

呼吸機能改善、姿勢矯正（猫背解消）、自律神経安定、デスクワーク疲労解消

押す・伸ばす手順

座って胸の前で指を組み、息を吸いながら両手を頭上高く裏返して伸ばし、息を止めて体を左右に倒し、吐いて脱力。
