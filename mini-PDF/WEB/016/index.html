01

Tops（セントラル・チェンライ店 / ท็อปส์ เซ็นทรัล เชียงราย）

チェンライ随一の輸入食材・日本食材の品揃え。ロイヤルプロジェクトの高冷地野菜、サーモン等の鮮魚、厳選チーズ・ワイン・洋食調味料が豊富。自社ベーカリー・総菜コーナー併設。

場所

セントラル・チェンライ G階（Floor G / 国道1号線沿い）

取扱日本食材

キッコーマン・ヤマサ醤油、みりん、料理酒、味噌各種、納豆（冷凍輸入）、冷凍讃岐うどん、カレールー（バーモント・ジャワ等）、タイ産日本米「みのり」・日本直輸入米、伊藤園緑茶、日本菓子・即席麺。

💡 ポイントカード・特典

The 1カード（セントラル共通 / 25THB＝1ポイント、公式アプリ提示でポイント値引き・会員限定割引価格）。

02

Big C Supercenter Chiang Rai 1（市内南店 / บิ๊กซี เชียงราย 1）

生活密着型の大型総合ハイパーマーケット。食料品・生鮮食品から家電・衣料・日用品・文具までワンストップで調達可能。低価格PB商品（Happy Price）が充実。フードコート・銀行併設。

場所

チェンライ市街地南部・国道1号線沿い（セントラル北約500m）

取扱日本食材

ヤマモリ・キッコーマン醤油、めんつゆ、すき焼きのタレ、ぽん酢、キューピードレッシング、タイ産日本米、味の素、カレールー、日清即席麺、豆腐、冷凍たこ焼き。

💡 ポイントカード・特典

Big Point（25THB＝1ポイント、Big C公式アプリ連動でポイント即時値引・会員限定クーポン・特別特価適用）。

03

Big C Supercenter Chiang Rai 2（空港・バンドゥー店 / บิ๊กซี เชียงราย 2 สนามบิน）

エンタメ・外食複合型ハイパーマーケット。映画館（Major Cineplex）、大型フードコート、人気レストラン（MK、やよい軒、Shabushi等）が入居。広い駐車場完備で空港利用時にも便利。

場所

市内北部・バンドゥー地区（メーファールアン空港入口交差点近く）

取扱日本食材

ヤマモリ調味料、キッコーマン醤油、キューピーマヨネーズ、カレールー、日本米、タイ日清カップ麺、冷凍食品・豆腐・日本スナック菓子各種。

💡 ポイントカード・特典

Big Point（Big C全店共通 / アプリ提示でポイント蓄積・即時割引利用可能）。

04

Makro Chiang Rai（卸売スーパー / แม็คโคร เชียงราย）

CPグループ運営の会員制・業務用卸売スーパー（早朝06:00〜22:00営業）。大容量・まとめ買いで市内最安クラス。ブロック肉・鮮魚丸ごと・冷凍食材・PB「aro」調味料が圧倒的ボリューム。一般個人も購入可能。

場所

市内北部・バンドゥー地区・国道1号線沿い（Big C 2の北側）

取扱日本食材

業務用1L〜1.8L大容量醤油・つゆ・タレ（ヤマモリ/キッコーマン）、業務用1kgカレールー、業務用1Lごまドレッシング、日本米大袋（5kg〜25kg）、業務用冷凍うどん（大袋）、冷凍サーモン柵・サバ・鰻、冷凍たこ焼き（大袋）。

💡 ポイントカード・特典

Makro PRO（公式アプリ登録で誰でも即時会員バーコード発行・PROポイント還元・会員専用価格・配送注文対応）。

05

Lotus's（市内go fresh各店＆県内大型店 / โลตัส）

近隣での手軽な買い出しに最適なミニスーパー（go freshは24時間または早朝〜深夜営業）。自社PB「Lotus's」の調味料・冷凍食品・日用品が低価格。メーチャン等の大型店は総合品揃え。

場所

市内住宅地・幹線道路沿い（Sri Wiang、Night Bazaar等）およびメーチャン・メーサイ大型店

取扱日本食材

定番のヤマモリ・キッコーマン醤油、キューピードレッシング、タイ産日本米、パック豆腐、卵、冷凍餃子、タイ日清即席麺、日本スナック菓子（go freshは日常使いサイズ中心）。

💡 ポイントカード・特典

My Lotus's（旧Clubcard / Lotus's SMART Appまたは電話番号登録でLotus's Coinが貯まり、1コイン＝1THBとして即時割引利用可能）。
