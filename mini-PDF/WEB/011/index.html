01

ドイトゥン・ロイヤルヴィラ（皇太后宮殿 / พระตำหนักดอยตุง）

営業時間

08:00〜17:00

入場料(タイ人/外国人)

単館: 90THB（共通セット券: 220THB / シニア・学生: 110THB）※内外人同額

歴史・王室の取り組み

故シーナカリン王太后（メーファールアン）がアヘン撲滅と森林再生の拠点として1989年完成。スイス山荘（シャレー）とラーンナー様式が融合した木造建築で、輸送用木箱の廃材（松材）を再利用した質素倹約の美徳を体現。

おすすめ体験・お土産

王太后の質素で気品ある生活空間・執務室の見学、天井の星座木彫レリーフ鑑賞。王室プロジェクト特製ドイトゥンコーヒーやマカダミアナッツスイーツ。

02

メーファールアン庭園（สวนแม่ฟ้าหลวง）

営業時間

08:00〜17:00

入場料(タイ人/外国人)

単館: 90THB（共通セット券: 220THB / シニア・学生: 110THB）※内外人同額

歴史・王室の取り組み

かつてのアヘン輸送路・ケシ畑だったすり鉢状の谷間（約12エーカー）を再生した広大な温帯植物園。中央には彫刻家ミーシアン作の「継続こそ力」を象徴する子供たちのブロンズ像「コンティニュイティ」が建つ。

おすすめ体験・お土産

四季折々に咲き誇る温帯花卉・高山植物の鑑賞と記念撮影。敷地内「Café DoiTung」での淹れたてアラビカコーヒー（EU・タイGI認証）の試飲。

03

インスピレーション・ホール（หอแห่งแรงบันดาลใจ）

営業時間

08:00〜17:00

入場料(タイ人/外国人)

単館: 90THB（共通セット券: 220THB / シニア・学生: 110THB）※内外人同額

歴史・王室の取り組み

マヒドン王家（シーナカリン王太后、ラーマ8世、ラーマ9世プミポン前国王）の生涯と人道支援・地域自立支援の歴史を伝える記念展示館。麻薬地帯から持続可能な楽園へ転換した開発哲学を体系展示。

おすすめ体験・お土産

国連薬物犯罪事務所（UNODC）にも認定された代替開発モデル（Alternative Development）のインタラクティブ映像展示・歴史資料の学習体験。

04

メーファールアン・樹木園（ドイ・チャン・ムーブ / สวนรุกขชาติดอยช้างมูบ）

営業時間

08:00〜17:00

入場料(タイ人/外国人)

単館: 90THB（共通セット券: 220THB / シニア・学生: 110THB）※内外人同額

歴史・王室の取り組み

標高約1,500mの国境尾根沿いに位置する高山植物園。アジア各地の希少なシャクナゲ（กุหลาบพันปี）コレクション、野生ラン、ヒマラヤザクラが松林の中に広がる。

おすすめ体験・お土産

松林の自然歩道トレッキング、隣接する国境警備拠点からのミャンマー側山並み・大雲海のパノラマ絶景鑑賞。

05

ドイトゥン・ツリートップウォーク（ดอยตุง ทรีท็อปวอล์ค）

営業時間

08:30〜16:30（約30分ごとのツアー形式）

入場料(タイ人/外国人)

150THB/回（※別途メーファールアン庭園入場券が必要）

歴史・王室の取り組み

自然環境を損なうことなく森林と共生するエコツーリズムとして庭園内に新設。地元高地民族スタッフが専任ガイド・安全管理を担当し雇用を創出。

おすすめ体験・お土産

安全ハーネスを装着し、地上高10〜40m・全長約300mの吊り橋から鳥の目線で原生林やコーヒー農園を望む空中散歩（対象: 身長120cm以上・12歳以上）。
