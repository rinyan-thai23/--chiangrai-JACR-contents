01

ワット・チェディルアン（Wat Chedi Luang / วัดเจดีย์หลวง เชียงแสน）

チェンセーン最大級の八角形多層基壇ベル型大仏塔（基壇幅24m）、大破した巨大レンガ造り主仏坐像（降魔成道印）とウィハーン（本堂）円柱列遺構。

時代・歴史的背景

1331年、メンラーイ王の孫・第3代セーンプー王（King Saen Phu）により建立。旧城壁の中心に位置するランナー初期の最高格式寺院。

レンタサイクル/移動

旧市街中心部に位置し完全平坦でアクセス抜群。国立博物館のすぐ東隣。

拝観料・開館時間

無料 / 06:00〜18:00（毎日）

02

ワット・パーサック（Wat Pa Sak / โบราณสถานวัดป่าสัก）

スコータイ・パガン・ハリプンチャイ様式が高度に融合したプラサート型仏塔。壁面ニッチに残るガルーダ、キンナリー、守護神、仏立像の精巧な漆喰浮彫（スタッコ）。

時代・歴史的背景

1340年、セーンプー王が寺院周囲に300本のチーク（サック）の木を植え仏舎利を奉納。旧城壁西門（プラトゥー・パーサック）の外側に位置。

レンタサイクル/移動

西門を出てすぐ。木立に囲まれた静寂な未舗装路あり（平坦）。

拝観料・開館時間

外国人: 50THB / タイ人: 10THB / 08:00〜17:00（毎日）

03

ワット・プラタート・チョームキッティ（Wat Phra That Chom Kitti / วัดพระธาตุจอมกิตติ）

金箔の十二角形削り角ランナー仏塔。約300段のナーガ（竜王）階段を登った山頂展望デッキからメコン川、対岸ラオス、古都全景を一望する大パノラマ。

時代・歴史的背景

伝承では10世紀、ヨノック王国のプロム大王が頭髪仏舎利を納めて建立。1487年にランナー様式で改修。城壁北西の丘陵「ドイ・ノイ」頂上に鎮座。

レンタサイクル/移動

丘陵の登り坂手前に駐輪スペースあり（徒歩で階段を登る）。山腹に姉妹塔チョームチェンあり。

拝観料・開館時間

無料 / 06:00〜18:00（毎日）

04

チェンセーン国立博物館（Chiang Saen National Museum / พิพิธภัณฑสถานแห่งชาติ เชียงแสน）

丸顔と蓮の蕾の肉髻が美しい「チェンセーン様式」青銅仏像コレクション、ハリプンチャイ期テラコッタ、石碑銘文、山岳民族（アカ・モン族等）民俗資料。

時代・歴史的背景

1957年、タイ芸術局により開館。古代チェンセーン王国およびランナー初期の美術工芸・出土遺物を保存展示する北タイ重要博物館。

レンタサイクル/移動

ワット・チェディルアン隣。駐輪スペースあり。

拝観料・開館時間

外国人: 100THB / タイ人: 20THB / 08:30〜16:30（水〜日開館 / 月火祝休）

05

旧城壁・城門＆メコン川沿いサイクリングロード

南門（ナンセーン門）、西門（パーサック門）のレンガ遺構。メコン川堤防沿いに整備された雄大なリバーサイド遊歩道（対岸ラオスの山並みを望む）。

時代・歴史的背景

1328年頃セーンプー王が築いた不整形長方形の城塞都市。西・北・南の3面に二重土塁・濠・レンガ城壁が残存（東面はメコン川が天然の要害）。

レンタサイクル/移動

メコン川沿い観光センターやゲストハウスで自転車レンタル（約20〜100THB/日）。城郭内は全域平坦で交通量も少なく快適。

拝観料・開館時間

無料 / 24時間散策可能（日中・夕方の走行を推奨）
