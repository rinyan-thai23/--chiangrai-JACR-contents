# TSV・イラスト画像データを出力する部署
50idea.txtを参照し、1行ずつTSVデータおよびイラスト画像を出力します。

ゴール：
TSV出力、リサーチレポート出力、およびインフォグラフィック画像出力

目的：
コンテンツ化
画像PDF化（旅行者の印刷・持ち歩きを想定）

成果物出力：
1. TSVデータ: `TSV/` ディレクトリ
   - `001-チェンライ市内の主要寺院（ワット・プラケオ、青・白の寺等）拝観ガイド.tsv`
2. リサーチレポート: `TSV/` ディレクトリ
   - `001-1リサーチデータレポート.md`（TSVを作成した経緯、取得元URL、検証記録を書く）
3. イラスト画像: `img/` ディレクトリ
   - `001-a.jpg`（A4縦型：日本語入り手書き風/フラットイラスト画像、情報凝縮・賑やかで楽しいデザイン、**背景は白/クリーンな印刷向け背景**）
   - `001-b.jpg`（A4横型：日本語入り手書き風/フラットイラスト画像、周遊マップ・見開きデザイン、**背景は白/クリーンな印刷向け背景**）

制作・検証工程：
1. **リサーチフェーズ**:
   - 旅行者向けの実用情報のため、ファクトチェックは厳格に行い合格ラインを徹底すること。
   - リサーチはできるだけ丁寧に行い、時間を掛けること。「最後の一件が埋まらずついデータを架空に作ってしまうこと」は絶対に禁止。
   - リサーチやフェッチはタイ語・英語の順番で行うこと（日本語は不要）。
2. **TSV・レポート作成**:
   - 50idea.txtのデータスキーマに厳密に沿ってTSVを出力。
   - リサーチレポートに取得経緯、参照元URL、ファクトチェック内容を詳細に記録。
3. **検収フェーズ**:
   - 1つのTSV作成ごとに検収エージェントを呼び出して厳格にチェック（フォーマット、スキーマ、架空データ排除）。
4. **画像出力フェーズ**:
   - TSVのデータを元に、日本語入りの手書き風イラスト / フラットイラスト画像をA4縦型（-a.jpg）およびA4横型（-b.jpg）の2パターン作成し、`img/` フォルダに保存する。
   - **重要**: 旅行者の印刷や閲覧を想定し、**画像の背景は白（ホワイトベース）**とすること（インク消費や印刷時間を考慮）。A4サイズ1枚に全情報を詰め込み、賑やかで楽しい雰囲気に仕上げる。
