# 027-1 リサーチデータレポート：北タイ伝統ハーブとカントーク料理の健康効果

## 1. 概要と作成経緯

本レポートは、`50idea.txt` の ID: 27「北タイ伝統ハーブ（サムンプライ）とカントーク料理の健康効果」に基づくTSVデータ作成における調査プロセス、データソース、および検証経緯を記録したものです。

タイ北部（ランナー文化圏）に伝わる食文化は、「**キン・ペン・ヤー（กินเป็นยา / 食べる薬）**」というタイ伝統医学の根本思想に基づき、肉料理や油分の多い料理（サイウア、ゲーンハンレー、ラープ・クア等）に対し、辛温性の駆風ハーブ（マクウェン、タクライ、カミン）を調合し、苦味・冷涼性を持つ豊富な生野菜・茹で野菜（バイ・チャップルー、マクワ・プロ、ドーク・ケー、パック・パイ等）を組み合わせることで、消化吸収・整腸・血糖値安定・抗酸化などの優れた薬膳的相乗効果を生み出しています。

本調査では、タイ保健省タイ伝統医療・代替医療開発局（DTAM `dtam.moph.go.th`）、チェンマイ大学（CMU）ランナー食文化アーカイブ・薬学部、マヒドン大学薬学部薬用植物情報センター等の公的一次情報を基に、代表的な8大ハーブ・伝統野菜のタイ語/ランナー方言名、薬理成分・効能、カントーク料理での具体的活用法を厳格にファクトチェックしました。

---

1. **言語優先順位**:

   - 二次調査: マヒドン大学薬学部 `medplant.mahidol.ac.th`、王室植物遺伝資源保全プロジェクト（RSPG `rspg.or.th`）

2. **検証項目**:
   - ハーブ・野菜の正確なタイ語名・ランナー方言名・学名（マクウェン/バークウェン、トゥアナオ・ケープ、カミン・チャン/バーミン、タクライ/ジャクライ、バイ・チャップルー/パックプーナー、マクワ・プロ/マクワ・チェー、ドーク・ケー/ケー・カーオ、パック・ペーオ/パック・パイ）
   - 主要薬理成分（リモネン、クルクミン、シトラール、納豆菌酵素、β-カロテン、アルデヒド等）
   - 科学的・伝統医学的効能（健胃・駆風、抗炎症、血栓予防、血糖値抑制、風邪予防「แก้ไข้หัวลม」等）
   - カントーク料理での調理・食べ合わせ（ラープクア、サイウア、ゲーンハンレー、ナムプリック、ミエン包み、生食/茹で）

## 3. 各ハーブ・伝統野菜のリサーチ詳細と裏付けデータ

### ① マクウェン（มะแขว่น / Makwaen）
- **タイ語/方言/学名**: มะแขว่น / บ่าแขว่น / *Zanthoxylum limonella*
- **事実確認**:
  - リモネン、サンショオール類。健胃・駆風（ガス解消）、血行促進、抗菌作用。
  - ラープ・クア専用スパイス（プリック・ラープ）やサイウアに配合。柑橘系の芳香としびれを付与。

---

### ② トゥアナオ（ถั่วเน่า / Thua Nao）
- **タイ語/方言/学名**: ถั่วเน่า / ถั่วเน่าแข็บ / 原料: *Glycine max* / 発酵菌: *Bacillus subtilis*
- **事実確認**:
  - 植物性タンパク質、遊離グルタミン酸、納豆菌酵素、イソフラボン。整腸、血栓予防。
  - 炙って粉末化しナムプリック・オーンやナムギョウに練り込み、天然の旨味・コク（Umami）を付与。

---

### ③ カミン・チャン（ขมิ้นชัน / Khamin Chan）
- **タイ語/方言/学名**: ขมิ้นชัน / บ่ามิ้น / *Curcuma longa*
- **事実確認**:
  - クルクミン、ターメロン。抗酸化・抗炎症、胃粘膜保護、肝機能改善、胆汁分泌促進。
  - ゲーン・ハンレーやサイウアのペーストに配合。豚肉の脂質消化をサポートし黄色を付与。

---

### ④ タクライ（ตะไคร้ / Takhrai）
- **タイ語/方言/学名**: ตะไคร้ / จะไคร / *Cymbopogon citratus*
- **事実確認**:
  - シトラール、ゲラニオール。消化促進・鎮痙、抗菌・防腐、利尿・むくみ解消。
  - サイウアに刻んで大量に練り込み、肉の脂っこさを中和してサクサク食感を生み出す。

---

### ⑤ バイ・チャップルー（ใบชะพลู / Bai Chaplu）
- **タイ語/方言/学名**: ใบชะพลู / ผักปูนา / *Piper sarmentosum*
- **事実確認**:
  - 豊富なβ-カロテン、カルシウム、ビタミンA・C。血糖値抑制、抗酸化、骨強化。
  - ナムプリック・ヌムやオーン、ラープ・クアを葉で包んで食べる（ミエン包み）。ゲーン・ケーの具。

---

### ⑥ マクワ・プロ（มะเขือเปราะ / Makhuea Pro）
- **タイ語/方言/学名**: มะเขือเปราะ / มะเขือแจ้ / *Solanum virginianum*
- **事実確認**:
  - 食物繊維、ナスニン、クロロゲン酸、カリウム。食後血糖値急上昇抑制、脂質低減、整腸。
  - ヘタを取り十字に切り冷水で締め、カリッとした食感でナムプリック類を生ですくってかじる。

---

### ⑦ ドーク・ケー（ดอกแค / Dok Khae）
- **タイ語/方言/学名**: ดอกแค / แคขาว / *Sesbania grandiflora*
- **事実確認**:
  - ビタミンA・C、カルシウム、フラボノイド。季節の変わり目の風邪・発熱予防、健胃・緩下。
  - おしべ・めしべを取り除いてサッと茹で、カントークの茹で野菜（パック・ルアク）として食す。

---

### ⑧ パック・ペーオ / パック・パイ（ผักแพว / ผักไผ่ / Phak Phaeo）
- **タイ語/方言/学名**: ผักแพว / 北タイ名: ผักไผ่ (Phak Phai) / *Persicaria odorata*
- **事実確認**:
  - 脂肪族アルデヒド類、高濃度の鉄分、ケルセチン。消化促進、貧血予防、強い殺菌作用。
  - ラープ・クアに不可欠な生薬味（パック・カップ・ラープ）。爽快な香りで脂っぽさを消す。
