# タイ在住者のための道具箱（thai-pwa）

タイ在住者向けの小さなツールを、1つずつホーム画面に入れられるアプリ（PWA）として置く場所。
日本語と英語を切り替えられる。Cloudflare に1つの Worker として置く。

## 中身

| パス | 役割 |
|---|---|
| `site/` | 画面。ここに置いたものがそのまま公開される |
| `site/90day/` | 90日レポート（通知つき） |
| `worker/index.js` | 通知係。`/api/*` を受け取り、毎朝 8:00（タイ時間）に通知を送る |
| `wrangler.toml` | Cloudflare の設定（画面の場所・毎朝の時刻・データベース） |
| `tools/make_icons.py` | アイコンを作る（`python3 tools/make_icons.py`） |

新しいツールは `site/<名前>/` にフォルダを足す。フォルダごとに `manifest.webmanifest` と `sw.js` を置けば、別のアプリとしてインストールできる。

## 90日レポートの仕組み

- 入力は「次回の報告日」（受付票の日付）1つ。初めての人は入国日＋90日で計算できる
- 「通知を受け取る」を押すと、通知の宛先と期限日だけがサーバー（D1）に保存される。名前やパスポート番号は保存しない
- 毎朝、期限の **15日前・3日前・当日・期限後6日目（最終日の前日）** の人に通知を送る
- 通知は中身なしで送り、文面は端末の `sw.js` が端末に保存した日付から作る
- 通知の鍵（VAPID）は、最初のアクセスのときに自動で作って D1 に保存する。手で秘密鍵を扱わなくてよい
- 宛先が無効になった（アプリを消した等）登録は自動で削除する。期限から60日たっても更新されない登録も削除する

## Cloudflare に置く手順（最初の1回だけ）

スマホのブラウザでもできる。順番を守る（2 の ID が入る前に 3 をすると、最初のデプロイが失敗する）。

1. **Cloudflare のアカウントを作る**（無料）：https://dash.cloudflare.com/sign-up
2. **データベースを作る**
   - 「ストレージとデータベース」→「D1」→「データベースを作成」、名前は `thai-pwa`
   - 表示される **データベースID** を Claude に送る → `wrangler.toml` に書き込んで `main` にプッシュしてもらう
   - この ID は秘密の情報ではないので、チャットに貼ってもリポジトリに書いてもよい
3. **このリポジトリをつなぐ**（Claude のプッシュが終わってから）
   - 「Workers & Pages」→「作成」→「リポジトリをインポート」→ GitHub をつなぐ → `smartphone-create` を選ぶ
   - プロジェクト名：`thai-pwa`（`wrangler.toml` の name と同じにする）
   - ルートディレクトリ：`thai-pwa`
   - ビルドコマンド：空欄／デプロイコマンド：`npx wrangler deploy`（初期値のまま）
   - 「デプロイ」
4. **開く**：`https://thai-pwa.<アカウント名>.workers.dev/90day/` を Android の Chrome で開く →「︙」→「アプリをインストール」

以後は `main` にプッシュするたびに自動でデプロイされる。Claude はプッシュするだけでよく、Cloudflare の鍵はいらない。

## Claude にここから直接デプロイさせたいとき（任意）

Git 連携だけで足りる。次のことまで Claude にさせたいときだけ設定する：本番のデータベースの中身を見る、ログを見る、プッシュせずに試しに出す。

1. Cloudflare で API トークンを作る（「プロフィール」→「API トークン」→「Workers を編集」のテンプレート＋ D1 の編集権限）
2. Claude Code のクラウド環境の設定（画面上部の環境メニュー →「編集」）で、環境変数に入れる
   - `CLOUDFLARE_API_TOKEN` = トークン
   - `CLOUDFLARE_ACCOUNT_ID` = アカウントID
3. 同じ設定の「ネットワークアクセス」で `api.cloudflare.com` を許可する（今は遮断されている）
4. 新しいセッションから使える

トークンはチャットに貼らない。リポジトリにも書かない。

## 確認済みのこと（2026-10-05）

- ローカルの Cloudflare 環境（wrangler dev）で、登録・解除・テスト通知・毎朝の処理が動くこと
- 許可していない宛先（Google・Apple・Mozilla・Microsoft の通知サーバー以外）を弾くこと
- 通知の署名（VAPID）が正しいこと。Google の通知サーバーまで届き、存在しない宛先は自動で消えること
- 日付の計算（入国日＋90日、報告できる期間、期限後の表示）
- 日本語・英語の切り替え、ダークモード

未確認：実機（Android・iPhone）で通知が届くところ。Cloudflare に置いたあと、アプリの「テスト通知」で確かめる。

## 注意

- 報告できる期間は「期限の15日前〜7日後」で表示している。オンライン報告の受付期間はこれと違うことがあるので、画面では公式サイトへのリンクだけ出している
- iPhone はホーム画面に追加したときだけ通知を受け取れる
